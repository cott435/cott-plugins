# toy 0.2 — overview

Branch: `toy-0.2`. A fixture plan for plugin-dev's `run-phase` evals. Nothing here bumps or
tags anything.

## Why

`toy` can say hello (`greet`) but not goodbye. 0.2 adds `farewell`, the mirror of `greet`:
the same frontmatter shape, and one line written to `outputs/farewell.txt`,
`Goodbye, <name>.`

None: `farewell` is read by nothing else.
