# User's answers (use these whenever the skill would ask; for anything not covered, pick the option you marked Recommended)
- Who/purpose: me, an ML engineer. Today I skim arXiv and forget most of what I read.
- Jobs I want: (1) a deep read of one paper — method, claims, whether the experiments support them; (2) a literature review on a topic I name; (3) a weekly digest of new arXiv papers in my areas, ranked by relevance to what I work on.
- Source material: arXiv PDFs and their references; code repos when linked. A careful reader checks each claim against its experiments.
- Data access: arXiv API and WebFetch, no keys. Semantic Scholar API for citations (free).
- My areas: a YAML file of topics and keywords I edit (config/areas.yml). Weekly digest typically sees ~150 new papers, of which ~20 are worth a look.
- Outputs: markdown notes in the repo.
- Boundaries: read-only research; never posts or emails anything.
