## What was tested

`python-style-guide` now forbids options bags and unnamed calls on a main path, asks for
docstring summaries written from the caller's side, reserves `log` for logging, forbids a
private class name shared by sections that call each other, and points at a new
`references/pipelines.md`, which has the shape of a pipeline and a section orchestrator and
the four-item reader's test. The claim: the guide still passes the bundle's contracts,
registers, and makes an agent that follows it write a pipeline as named steps, meet a size
limit with keyword-only parameters and real seams, and write caller-side docstrings and
names. It should do all of this better than the 2.4.0 guide.

## Method

- **3.1:** `contract_sweep.py` from `plugin-dev` 0.15.0, run from the plugin directory.
- **3.2:** a `grep` for the four numbered lines in `references/pipelines.md`, and a `grep`
  for `pipelines.md` in **Scope**. `wc -l SKILL.md`.
- **3.3:** `claude --plugin-dir . -p "List the skills you have from dev-team"`, run once.
- **3.4:** `run-evals`, one run per configuration per eval. Executors were general-purpose
  subagents on Sonnet 5.5, each given the skill file to Read first: the working tree's for
  `with_skill`, the `d6ec777` snapshot's for `old_skill`. Graders were skill-creator's
  `grader.md` on Sonnet 5.5. Each grader prompt had one sentence added: the path of the
  task's original input under `evals/sets/files/python-style-guide/`, so it could check the
  "unchanged" expectations. Eval 2's graders were also given `uvx ruff@0.16.9`.
- **Reruns and repairs:**
  - Eval 1 `old_skill` ended on an API error, a Sonnet 5.5 safeguard flag
    (`reasoning_extraction`), before it wrote its transcript. Its outputs were emptied and
    the run was spawned again. Timing comes from the rerun.
  - Eval 3 `with_skill` wrote its `transcript.md` into `outputs/`. Before grading, the
    file was moved to the run directory. Nothing else in the run was touched.
- **Blind comparison:** not run. The pass rates are 26 points apart, and the note's row
  does not ask for one.
- About 476k executor tokens and 393k grader tokens.
