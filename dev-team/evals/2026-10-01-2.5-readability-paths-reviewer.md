## What was tested

The reviewer with `Focus: paths` and a `Package:` field writes one paths report per package
at `reviews/paths/<date>-r<n>-p.md` with the template's seven headings plus **Paths**, copies
the `--paths` footer counts, blocks only on P1–P4 (each line `<section>: P<k> — <file:line>`),
scopes round 2 to the diff, and backlogs a demoted finding; the section reviews it already
did (evals 6–8, the 2.4 additions) are unchanged. Around it: `status.py --rounds <pkg>/paths`
prints five lines, the contracts hold the Focus values, the report's **Paths** heading and
the reader's-test items, and the plugin still loads.

## Method

- Row 6.1: `python3 <plugin-dev 0.15.0>/scripts/contract_sweep.py` from `dev-team/`, then two
  planted defects one at a time, each restored before the next: `Focus: path` on a line of
  `agents/reviewer.md`'s **Focus: paths**; `**Steps in sequence**` cited in P3 with `'Steps in
  sequence'` in the new claim's `cites`.
- Row 6.2: `PATH="$PWD/evals/workspace/bin:$PATH" python3 evals/fixtures/state-cases/check.py`
  (the shim runs `uvx ruff@0.16.9`); `hook-events` the same way as a regression check.
- Row 6.3: `claude --plugin-dir . -p "List the agents you have from dev-team" --model claude-sonnet-5-5`.
- Before row 6.4 (note step 7): each eval's tree (`evals/sets/files/reviewer/paths/` plus its
  overlay) was copied into a scratch git repo and `status.py --paths data` run there; each
  output was compared byte for byte with the block in the eval's prompt. The gate records'
  `MEASURED shape` lines were compared with `status.py --shape data --section <s>`; the
  `depth` lines, which `--shape` prints only for a section with a README, were checked by
  adding a one-row README per section in the scratch repo.
- Rows 6.4 and 6.5: `run-evals`, one run per configuration, executors as general-purpose
  subagents given the executor prompt (with the working tree's `agents/reviewer.md`, or the
  baseline snapshot's), the harness forbidding every command; one grader per run; `old_skill`
  is the snapshot at the baseline ref. 6.5 ran as its own iteration with `--baseline
  dev-team-v2.4.0`. Blind comparison for 6.5 (both configurations passed everything);
  comparator prompts staged in the session scratchpad. No run errored or was rerun.

## Verdict

The claim held. Row 6.4: every expectation passes for `with_skill` and its rate is far above
`old_skill`'s, which blocks on `Focus: paths` or falls back to a `full` review without
**Paths**. Row 6.5: no regression on the 2.4 section-review evals, and a blind preference for
the working tree on two of three. The mechanical rows pass. Executors listed fixture files
with `find` (their Glob tool was missing), which the corrected no-command expectation names.
