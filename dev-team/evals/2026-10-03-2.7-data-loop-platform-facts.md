# 2.7-data-loop platform fact P0.1 — `uv run --with duckdb` leaves `pyproject.toml` and `uv.lock` untouched

**Tested against:** uv 0.11.27 (`19fc8b03b`, aarch64-apple-darwin), CPython 3.11.15; no plugin file is under test, branch `dev-team-2.7-data-loop` at `1d05b3c` (uncommitted — see working-tree diff) · model: none (shell commands, run by Claude Opus 5.5 in the phase-0 chat) · 2026-10-03
**Set:** none — platform-fact row P0.1 of `site/notes/2.7-data-loop-00-overview.md` **Phases** · **Baseline:** — · **Pass rate:** 1/1

## What was tested

**P0.1** — `uv run --with duckdb python <script>` inside a uv project leaves `pyproject.toml`
and `uv.lock` unchanged, so the profiler's program (`docs/sources/<token>.profile.py`) can use
DuckDB as its query engine without adding a dependency to the repo (the design's decision
"The program's query engine").

## Method

Real runs, each in a fresh `mktemp -d` directory outside the repo. No cost beyond the
download of the `duckdb` wheel.

- **P0.1 as written.** `uv init --name probe`, `uv lock`, `git init`, commit everything; write
  `q.py` holding `import duckdb; print(duckdb.sql("select 1").fetchall())`; run
  `uv run --with duckdb python q.py`; then `git status --porcelain -- pyproject.toml uv.lock`.
- **Supplementary, a workspace with a member** (the design says "inside a uv workspace", and
  dev-team's scaffold is one). `uv init --bare --vcs none --name root` with
  `[tool.uv.workspace] members = ["packages/*"]`, `uv init --lib --vcs none --name data
  packages/data`, `uv lock`, `git init`, commit everything; the same `q.py` run with
  `uv run --with duckdb` once from `packages/data/` and once from the root; then
  `git status --porcelain --untracked-files=no`, `shasum` of `pyproject.toml`, `uv.lock` and
  `packages/data/pyproject.toml` before and after, and `grep -c duckdb uv.lock`.

## Verdict

The fact holds: `uv run --with duckdb` installs DuckDB into an ephemeral overlay and writes
neither `pyproject.toml` nor `uv.lock`, in a single project and in a workspace run from a
member or the root. The design's engine decision stands and phase 1 proceeds. Written back:
