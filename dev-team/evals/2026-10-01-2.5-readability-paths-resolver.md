## What was tested

`status.py --paths <pkg>` follows each `[project.scripts]` command through the package's own
code with a static resolver and prints its call tree: frames, `[indirect]` frames through a
lambda or a dict dispatch, `[effect: …]` leaves for third-party and I/O calls,
`[unresolved]` leaves, `[recursive]`/`[seen]`, and the three footer lines. The nine
`calltree-*` cases pin each rule. The plugin's contracts still hold.

## Method

- Row 4.1: `PATH="$PWD/evals/workspace/bin:$PATH" python3 evals/fixtures/state-cases/check.py`,
  the shim running `uvx ruff@0.16.9`. Each new case is `base`, then the new `commands` macro
  (five files, one commit), with one file replaced, then `--paths data`. `calltree-direct`
  matches the note's whole block as `\A<block>\n\Z`, so line for line and nothing else.
- Row 4.2: `python3 <plugin-dev 0.15.0>/scripts/contract_sweep.py` from `dev-team/`.
- Not in the table, run because the gate imports `status.py`: the `hook-events` suite under
  the same shim.
- By hand, in a scratch repo built from `calltree-direct` (not committed): a relative import,
  a re-export through `ingest/__init__.py`, a nested function and a lambda handed to one
  wrapper (two `[indirect]` frames, the second under `guarded … [seen]`), a `key=` lambda
  that is not printed, `pool.map(steps.clean, …)` (an `[indirect]` frame under the current
  function), `subprocess.run` as an effect, `log = logging.getLogger(…)` printing nothing, a
  target outside the package, a target the module lacks, and `--paths nope` (exit 2, `nope:
  missing docs/packages/nope/contract.md`). Bare `--paths` printed `--paths needs a package:
  status.py --paths <pkg>` and exited 2.
