That the implementer's 2.4 rules (E1–E16 of `site/notes/2.4-06-implementer.md`) and the
gate's new retry text hold: the return carries no check line and the README one name per row
(eval 13); after a scripted gate retry the run ends with the one line `Result: done` (14); a
