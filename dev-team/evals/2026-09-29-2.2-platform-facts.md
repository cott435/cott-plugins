## What was tested

The three facts `site/notes/2.2-design.md` lists as assumed, which phases 1, 3, 4 and 6 build on:

- **F1** — for a `PreToolUse` event inside a subagent, `<transcript_path without .jsonl>/subagents/agent-<agent_id>.jsonl` exists, so the guards can derive a subagent's transcript from the event alone.
- **F2** — that file's first record with `type: "user"` holds the Agent call's prompt verbatim, so a spawn prompt's `Section: <pkg>/<section>` first line is readable from it.
- **F3** — an import-linter `layers` entry written `(name)` is enforced when the module exists and skipped only when it is missing.

## Method

Real runs, one each, in the session scratchpad (never in this repo).

**F1, F2.** `evals/sets/files/hooks/build.sh <scratch>/in-scope <scratch>/out-scope` (no `--green`, as the overview's row writes it), then the in-scope repo's `.claude/settings.json` gained a project `PreToolUse` hook on `Write|Edit` running `sh -c 'cat >> <scratch>/events.jsonl'`. One `claude -p` session from that repo with `--plugin-dir ./dev-team`, `--permission-mode acceptEdits --allowedTools Agent`, told to spawn `dev-team:implementer` once with a three-line prompt whose first line is `Section: data/ingest`, asking it to Write `packages/data/src/data/ingest/f1_probe.py` and stop. The first try used `--dangerously-skip-permissions` and was refused by the outer session's permission classifier; the scoped flags above replaced it. Cost of the session: $0.22.

The recorded event was read for `transcript_path` and `agent_id`; the derived path was checked for existence and every record for a `type`; the first `type: "user"` record's `message.content` was compared byte-for-byte with the `prompt` of the `Agent` tool call in the parent transcript.

**F3.** A scratch uv workspace per `workspace-scaffold` §1–§3: root `pyproject.toml` with one member `data` and a contract-3-shaped layers contract, `containers = ["data"]`, `layers = ["(b)", "a"]`; sections `data/a` and `data/b`, with `import data.b` in `data/a/__init__.py` (a lower layer importing a higher one). `uv sync --all-packages`, then `uv run lint-imports` in four states: wrapped and unwrapped, `data/b` present and deleted (the import removed with it).

## Verdict

All three hold. The guards and the gate can derive a subagent's transcript from any hook event inside it (`transcript_path` minus `.jsonl`, then `/subagents/agent-<agent_id>.jsonl`), and read its section from the first `type: "user"` record's first line. The design's **Section-scoped write guard**, the gate's transcript rule and the **`(name)` unwrap** decision stand.
