# 03 — status.py: the surface's readiness and `--fields` line 7

Phase 3. `status.py` lets the `surface` row be ready at PLAN, DESIGN and TEST as soon as the
contract has a `## Call paths` heading, while IMPLEMENT and everything after still wait for
every other section; and `--fields` prints a seventh line, `dependency readmes:`, listing only
the dependency READMEs that exist on disk, so the driver can send the early surface designer and
tester `Dependency READMEs: none` without inspecting the repo. The state cases pin both. It
closes the gap between "the surface is designed right after PLAN" (the design) and a derivation
that today forces the surface row to wait for every sibling at every state
(`status.py:84-85`, `:598-601`, `package_table`).

## Decisions

- **The test is for the heading, not an entry.** `has_call_paths(pkg)` is true when
  `_item(contract text, "Call paths")` is non-empty. A `- none (no commands)` body counts: the
  heading is what says the contract was written under 2.6.
- **Only PLAN, DESIGN and TEST are freed.** PROBE never applies to `surface` (its `source` is
  `—`). IMPLEMENT, REVIEW, FIX and the states after keep the forced dependency, since the code
  needs the shipped entry points.
- **`dependency readmes:` lists files, not sections.** The seventh line holds
  `<path>/README.md` for each section in the row's `depends on` (for `surface`, every other
  section) whose file exists, in the Sections table's order, comma-separated; `none` when none
  does. The driver keeps prefixing `own: <path>/README.md` in `delta` and `document` modes, as
  today, since that is the section's own README, not a dependency's.
- **Appended as line 7.** Every existing `fields-*` case pins its lines with `contains`, so a
  new last line breaks none; the driver's tables (phase 4) name the line by its key.
- **`build.py`'s `base` gains `call_paths`.** `"call_paths": true` appends a `## Call paths`
  heading whose one entry is the `commands` macro's tree
  (`1 cli.load → 2 pipelines.run_load → 3 ingest.read_trades → shutil.copy`, budget 8), so a
  phase-5 case can compare a matching contract; a string value is written as the heading's body
  verbatim, for the mismatching cases. The default stays `false`, so every 2.5 case keeps its
  2.5 contract.

```python
def has_call_paths(pkg: str) -> bool:
    """True when the package contract has a `## Call paths` heading (2.6), whatever its body."""
    f = contract_path(pkg)
    return f.exists() and bool(_item(f.read_text(), "Call paths"))
```

```python
def dependency_readmes(pkg: str, section: str) -> list[str]:
    """`<path>/README.md` per section in the row's `depends on` that exists, Sections order."""
    row = _row(pkg, section)
    if row is None:
        return []
    by_name = {r["section"]: r for r in sections(pkg)}
    out = []
    for dep in _names(row["depends on"]):
        d = by_name.get(dep)
        if d is None or dep == section:
            continue
        readme = ROOT / d["path"] / "README.md"
        if readme.exists():
            out.append(_rel(readme))
    return out
```

(`sections()` already rewrites the `surface` row's `depends on` to every other section, so the
loop needs no special case.)
