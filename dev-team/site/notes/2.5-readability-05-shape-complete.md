# 05 — the shape check, complete

Phase 05. Phase 02's `status.py --shape` fails one kind of definition. This phase adds the
rest of what the design gives it: a second failing kind, the options bag (`**name:
Unpack[...]`), which the style guide forbids since phase 03; two measures the gate records
and never fails on, the section's indirect calls and the depth below each of its entry
points, the second computed with phase 04's resolver; and the base for an adopted section, so
code that was there before dev-team is measured and never failed. The gate itself does not
change: `check_shape` already copies every `PASS`, `FAIL` and `MEASURED` line.

## Decisions

- **The added lines of an adopted section** follow the design's **Decisions taken** row of
  that name: with no review round and a design whose first line is `Mode: document`, the base
  is the commit that added the design. Otherwise the base is phase 02's.
- **An options bag is judged on any function, public or private**, in the section's non-test
  code. The design's rule names the signature, not the name's visibility.
- **`MEASURED shape indirect` is a count of syntax, over the whole section**, not of the tree
  `--paths` prints and not only of added lines: a measure describes the section as it stands.
- **`MEASURED shape depth` uses the deepest effect below the entry point**, as the design's
  Outputs section words it ("the deepest static intra-package path from it to a call that
  leaves the package"), with phase 04's effect rule deciding what leaves.
- **The `surface` section's entry points are the package's commands.** Its README is
  `interface.md`, which has no **Entry points and interfaces** table; the commands are what
  the section exists to expose, and `[project.scripts]` names them.
- **`hooks/gate_on_stop.py` is not edited**, so the `hooks` set is not rerun.

## Specification

### The base

`shape_base(pkg, section)`, used by `--shape` in place of `review_base`:

1. the newest review round's `Commit:`, when it is an ancestor of `HEAD` (`review_base`'s
   first branch);
2. else, when the design exists, its mode word (as `spawn_fields` reads `design mode:`) is
   `document`, and `git log --diff-filter=A --format=%H -1 -- <design>` gives a commit: that
   commit;
3. else the empty tree.

### The lines, in the order printed

```
FAIL shape: <file>:<line> trivial-helper <name>
FAIL shape: <file>:<line> options-bag <name>
MEASURED shape indirect: <n>
MEASURED shape depth <entry point>: <n>
PASS shape <pkg>/<s>
```

FAIL lines first, sorted by file then line; then the one `indirect` line; then one `depth`
line per entry point, in the README's row order; then `PASS shape <pkg>/<s>` when no FAIL
line was printed. The `MEASURED` lines are printed whether or not anything failed.

- **options-bag.** A function or method in the files judged, its `def` line added, whose
  `**` parameter is annotated with a subscript of `Unpack` (`ast.arguments.kwarg.annotation`
  an `ast.Subscript` whose value is the name `Unpack` or an attribute ending `.Unpack`).
  `<name>` is the function's name, `Class.method` for a method.
- **indirect.** Over every file judged, added or not: the number of lambdas that are an
  argument of a call (positional or keyword), plus the number of names passed as an argument
  that are functions nested in the enclosing function, plus the number of calls whose function
  is a subscript (`_RUNNERS[stage](…)`).
- **depth.** One line per name in the section README's **Entry points and interfaces** table
  (`_name_cells`, the first identifier of each row); for `surface`, one per
  `[project.scripts]` command, named by the command. The value is the resolver's deepest
  effect below the entry point, the entry point's own frame at 0; a class's value is the
  largest over its public methods. `none` when no effect lies below it; `unresolved` when
  the name is not a function or class defined in the section's code. With no README, and for
  `surface` with no commands, no `depth` line is printed.

The **Shape.** paragraph of the docstring gains the second FAIL bullet, the two MEASURED
bullets and the three-step base, in the wording above.

### `skills/status/SKILL.md`

The `--shape` paragraph becomes:

```
`--shape <pkg> --section <s>` prints the section's shape check, the lines the stop gate copies
into its record. `FAIL shape: <file>:<line> trivial-helper <name>` is a private helper with one
call site in the package and three statements or fewer; `FAIL shape: <file>:<line> options-bag
<name>` is a signature taking `**name: Unpack[...]`. Both are judged only on lines added since
the section's last review (for an adopted section not yet reviewed, since its `Mode: document`
design was committed). `MEASURED shape indirect: <n>` counts the section's lambdas and closures
passed as arguments and its calls through a mapping, and `MEASURED shape depth <entry point>:
<n>` gives the deepest path from each README entry point to a call that leaves the package;
neither fails. `PASS shape <pkg>/<s>` follows when nothing failed. Exit 1 on a FAIL line.
```

### `state-cases`: eight cases

Each builds `base`, `design`, `tests`, `build` for `ingest` unless the row says otherwise, and
runs `--shape data --section ingest`. `bag.py` is `packages/data/src/data/ingest/bag.py`:

```python
"""Options."""

from typing import TypedDict, Unpack


class LoadOptions(TypedDict):
    """Options for a load."""

    strict: bool


def load_with(path, **options: Unpack[LoadOptions]):
    """Load path with options."""
    return path, options
```
