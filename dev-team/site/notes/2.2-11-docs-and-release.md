# 11 — docs-and-release

Phase 11. Everything a reader of the plugin sees: `README.md`, `site/flow.md`, the workflow
pages, the CHANGELOG's unreleased section, the six `contracts.yml` claims that hold the 2.2
paths and defaults against drift (each proven with a planted defect), the fixture READMEs; the
end-to-end eval of the whole two-package build under 2.2; the fourth assumed platform fact
observed from its streams; and the release proposal — MINOR, `2.2.0` — said in chat and left
to `bump-version` on a yes. The gap it closes: every earlier phase changed a file the README
describes, and the branch is not releasable while the README says implementers run one at a
time.

## Decisions

- **MINOR.** Defaults change (parallel and mixed batches, `SKIPPED` repo pytest), new
  locations are written, one spawn field is renamed — and nothing a user types is renamed or
  removed, every old location is still read. Reason: **What must not break**; `bump-version`
  decides on a yes.
- **The six `forbid` claims scope with `files:` and exempt with `near:`**, so a sentence that
  names an old path as "still read" passes and a sentence that writes to it fails. Reason:
  `contracts.yml`'s own precedent (`near: 40` on the claim about a repo's script directory).
- **Eval 4's harness plants a `repo`-scope pytest row** in the fixture copy's
  `docs/constraints.md` before the build (the two-package fixture's `tests pass` row is
  `package` scope), so the `SKIPPED` expectation is not vacuous. Reason: the eval writer's
  finding.
- **F4 is observed, not tested**: from eval 4's streams, two `SubagentStop` hook runs for two
  implementers of one batch whose record timestamps (the write time at the end of each gate run) fall inside the other's gate window, taken from the stream's hook events where present, else from header stamp to file mtime. Reason: the design says only CPU
  depends on it.

- **Running a package** 3 becomes: "**The ready set.** A section is ready when … The driver spawns every ready row's step in one message — probes, designs, tests, implementers, reviewer pairs together, whatever step each row is at — with one exception: a PLAN row runs the architect alone, since it edits what designers read. - **Hooks**: "registers five": the two new bullets, and the gate bullet rewritten: section from the spawn prompt in the transcript; diff since the last review; intent and unit suites; `package` rows; `repo` pytest `SKIPPED` (CI's); ELSEWHERE for any located failure outside the section the run did not touch; the retry rule; the record header. ### `contracts.yml` — six `forbid` claims

```yaml
  - name: no file writes to the 2.0 ledger path
    # Since 2.2 the section ledger is docs/packages/<pkg>/deviations/<section>.md; the 2.0 path
    # is read, never written. A writer told the old path splits one section's entries in two.
    pattern: 'docs/deviations/<pkg>/<section>\.md|docs/deviations/\$pkg/|docs/deviations/<pkg>/\*'
    near: 90
    unless: ['older', 'still read', 'pre-2.2', '2.0 ', 'edited in place', 'where it is']
    files: ['agents/*.md', 'skills/**/*.md', 'README.md', 'site/flow.md', 'site/workflows/*.md']

  - name: no file writes a review report to docs/reviews/
    pattern: 'docs/reviews/<date>|docs/reviews/\*-<pkg>|Write to `docs/reviews/'
    near: 90
    unless: ['older', 'still read', 'pre-2.2', '2.0 ']
    files: ['agents/*.md', 'skills/**/*.md', 'README.md', 'site/flow.md', 'site/workflows/*.md']

  - name: no file writes a change file to docs/changes/
    pattern: 'docs/changes/<slug>\.md|docs/changes/\*'
    near: 90
    unless: ['older', 'still read', 'pre-2.2', '2.0 ']
    files: ['agents/*.md', 'skills/**/*.md', 'README.md', 'site/flow.md', 'site/workflows/*.md']

  - name: the stop marker is per section
    # .dev-team/stop/<pkg>/<section>; a bare .dev-team/stop is 2.1's and a sibling's marker
    # under parallel implementers.
    pattern: '\.dev-team/stop\b(?!/)'
    files: ['agents/*.md', 'skills/**/*.md', 'hooks/*.py', 'README.md', 'site/**/*.md']

  - name: the tester's mode field is Design mode
    pattern: 'Adopted code'
    files: ['agents/*.md', 'skills/**/*.md', 'README.md', 'site/flow.md', 'site/workflows/*.md']

  - name: nothing says implementers run one at a time except to describe --serial
    pattern: '[Ii]mplementers? (run )?(one at a time|never run in parallel|×1, sequential)|one implementer at a time'
    near: 120
    unless: ['--serial']
    files: ['agents/*.md', 'skills/**/*.md', 'README.md', 'site/flow.md', 'site/workflows/*.md']
```

`site/**/*.md` excludes nothing under `site/notes/`: the marker claim would catch this plan's
notes, which quote the old marker. Scope it `files: ['agents/*.md', 'skills/**/*.md',
'hooks/*.py', 'README.md', 'site/flow.md', 'site/workflows/*.md']` instead. For each claim:
plant the defect (write the old path once in `README.md`), run `check-contracts`, see the
FAIL name `README.md:<line>`, revert, and record all six in the log.
