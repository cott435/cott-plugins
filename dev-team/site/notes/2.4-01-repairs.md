# 01 — repairs

Phase 01. Five small repairs that nothing else depends on, so the three mechanical suites
are green before any rule changes: a fixture string that no longer matches the gate's text,
a contract claim that fails on every note naming a plugin-dev command, a stale comment in
`contracts.yml`, an eval set that names an API page path the plugin stopped writing, a
duplicated row in the eval index, and an unresolved commit cell in the 2.2 ledger. No agent,
skill or script changes, so every row is mechanical. The doubled sentences in
`agents/tester.md` (design, build order step 1) are removed in phase 8, as that phase's first
step: the file is edited once, and its eval set runs once.

## Decisions

- **The tester's doubled sentences move to phase 8.** A phase that edits an agent runs that
  agent's set, and phase 8 edits the same file. Open item 13 asks only that they go before
  anything else is edited there, which phase 8's first step does.
- **The claim is widened in its pattern, not with `unless`.** `unless` pardons a whole line,
  so a bare command written beside a plugin-dev one would pass. The existing comment on the
  claim says the same of `/reload-plugins`.
- **`documenter.json` is corrected, and the documenter set is not run.** The target,
  `agents/documenter.md`, does not change in 2.4.
